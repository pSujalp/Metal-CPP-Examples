```bash
 make clean && make && make run
```

### Prerequisites

* macOS
* Apple Silicon or Intel Mac with Metal support
* Apple Command Line Tools
* Metal Toolchain
* Make

* **Assimp**
```bash
 brew install assimp
```
* **GLM**

```bash
 brew install glm
```
